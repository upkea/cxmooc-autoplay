# 常见问题 / 排错

## 脚本装了但完全没反应

1. **Chrome 必须开启「允许运行用户脚本」**
   `chrome://extensions` → 右上角开发者模式 → Tampermonkey「详情」→ 打开 **Allow User Scripts**。没开这个，油猴里显示"已启用"也不会执行。

2. **装完/更新脚本后必须刷新页面**
   已经打开的标签页还在跑旧代码，按 F5 或 Ctrl+R。

3. 检查是否生效：油猴图标上应显示数字；页面左上角应出现小工具日志面板。

## 视频还是被暂停

- 内置的「视频守护」会在 `pause` 事件后自动 `play()`。如果你看到视频反复暂停又恢复（画面抖动），说明超星在强制暂停，属于平台反挂机机制，脚本只能不断纠正，**进度仍会向前走**。
- 学习通页面**不能最小化**，也不能被其他窗口完全遮挡。
- 兜底方案：用 `ahk/start.bat`，视频停住时按 **F6**（激活浏览器 + 按空格）。

## AHK 一直显示「没找到按钮」

- **页面缩放必须是 100%**（Ctrl+0）。模板是按 100% 缩放截的，缩放一变像素尺寸就变。
- 学习通页面必须可见（不能被遮挡/最小化）。
- 若你的屏幕分辨率/缩放与作者不同，需要重做模板：
  1. 开着「继续学习」提示截一张全屏图
  2. 用 Python + Pillow 裁出按钮（蓝紫色药丸，约 138×54 px @150% 缩放）
  3. 保存为 `template-continue.png`
  4. 运行 `start.bat --dry`（或 `check.bat`）确认能识别到

## AHK 识别到了但点不掉按钮

这是正常现象——那个提示**不响应鼠标点击**（实测系统级点击也无效）。有效的操作只有「点播放按钮」或「按空格」，所以脚本改为：

1. 优先读页面标题里的 `【需继续】` 标记（油猴脚本写入）
2. 有标记就激活窗口 → 按空格
3. 兜底的图像识别路径会尝试点击视频画面区域（不点提示本身）

如果按空格也无效，说明焦点不在播放器上——手动点一下视频画面再按空格。

## AI 答题没生效

1. `ai_key` 是否填了？**留空时仍走原题库逻辑**。
2. `ai_base` 结尾不要带 `/chat/completions`，只到 `/v1` 或 `/v4`（脚本会自动拼 `/chat/completions`）。
3. 打开 F12 控制台，看是否有 `AI 答题中（1/N）：题目…` 日志；报错信息会显示在那里。
4. 检查 key 是否过期、额度是否用完。

## AI 答错了 / 答不出来

- 模型能力问题：7B 级模型对**图片题、公式题、长材料阅读**基本无能为力。
- 可以换更强的模型（如 `glm-4-plus`、`deepseek-chat`、`qwen-plus`），或降低预期——选择题、判断题成功率较高。
- 多选题模型容易漏选，可适当把提示词里的要求写得更严格（在 `src/internal/app/ai.ts` 的 `BuildAIPrompt` 里改）。

## 提交到 GitHub 前请检查

- `userscript/cxmooc-tools.user.js` 里 `ai_key` 必须是 `""`（不要把自己的 key 传上去）
- `LICENSE` 里的 `<your-github-name>` 改成你自己
- 不要提交 `.log`、`tmp/`、`node_modules/`（`.gitignore` 已处理）
